# CommII_A1_G4 

# **Laboratorio 5 - Modulación M-QAM**

En esta práctica se implementaron y analizaron diferentes tipos de modulaciones digitales, entre ellas: BPSK, QPSK, 8PSK y 16-QAM, utilizando la plataforma GNU Radio. La simulación se realizó tanto en escenarios de **banda base** como de **pasabanda**, lo cual permitió tener una visión más completa y cercana a situaciones reales de transmisión.

Para cada tipo de modulación se estudiaron tres aspectos fundamentales:
- **Constelación** (representación gráfica de los símbolos modulados),
- **Espectro de frecuencia** (análisis del uso del ancho de banda),
- **Tasa de bits** (eficiencia de la transmisión).

También se introdujo **ruido gaussiano (AWGN)** para observar cómo afectan las perturbaciones al rendimiento de cada modulación. Finalmente, se usó un **conversor ascendente (up-converter)** para simular el comportamiento de la señal modulada cuando se transmite en frecuencias más altas.

---

## Lo que se logró

Gracias a esta práctica se logró:
- Comprender la relación entre complejidad de la modulación y robustez frente al ruido.
- Identificar cómo modulaciones complejas como 16-QAM permiten mayores tasas de transmisión pero son más sensibles a errores.
- Simular de forma realista sistemas de comunicación usando versiones pasabanda.

También se reforzaron habilidades técnicas en:
- Manejo de trabajo colaborativo.
- Análisis comparativo de resultados en condiciones ideales y ruidosas.
